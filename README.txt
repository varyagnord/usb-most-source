USB Мост

Передача выбранных USB-устройств с Android-телефона или планшета на компьютер
через сеть. Этот репозиторий содержит соответствующие исходники выпусков,
ресурсы, лицензии и инструкции сборки. APK, AAB, ключи подписи и частные журналы
здесь не размещаются. Версии исходников сохраняются в неизменяемых тегах
v<versionName>-vc<versionCode>.

Возможности
- До четырёх одновременно передаваемых USB-устройств; отдельный выбор устройств,
  обнаружение подключения и отключения, имена и явные правила для каждого ПК.
- SSH с проверкой ключа компьютера и подготовкой приёмника при наличии прав;
  защищённое TLS-подключение по QR/коду к заранее установленному приёмнику.
- Обычный USB/IP в доверенной локальной сети. Между разными сетями нужен
  доступный сетевой путь; Tailscale можно использовать как дополнительный VPN.
- Сохранённые компьютеры, отдельные учётные данные и доверие, локальная
  диагностика, уведомление и плитка быстрого запуска.
- Запрос безопасного извлечения накопителя к принимающей ОС. Сообщение об
  успешном извлечении появляется только после её подтверждения. Если накопитель
  занят или механизм ОС недоступен, принудительное отключение не выполняется.

Собственный сервер USB Моста, облачный аккаунт, рекламные и аналитические SDK
не требуются. USB-передачи идут между устройствами пользователя. SSH и TLS
шифруют соединение; обычный USB/IP собственного шифрования не имеет.

Требования и границы поддержки
Android 8.0 и новее, USB Host/OTG и системное разрешение для выбранного USB.
Встроенные приёмники: Windows x64 и Linux x86_64 с systemd и vhci_hcd.
Для извлечения из приложения в Linux дополнительно нужен UDisks2. При его
отсутствии накопитель извлекают средствами компьютера. Отсутствующие пакеты
ядра/дистрибутива устанавливает администратор; приложение сообщает о них.
Драйверы самого USB-устройства и прикладные программы на ПК устанавливаются
отдельно, когда этого требует производитель устройства.

Поддерживаются USB control, bulk и interrupt. Изохронные передачи и USB bulk
streams не поддерживаются. Не обещается совместимость с любым оборудованием:
Android может не предоставлять приложению отдельные системные USB-интерфейсы.
Высокая задержка сети влияет на интерактивность и сроки операций; USB-команды
записи не повторяются вслепую после обрыва. Поддержки macOS/iOS нет.

Автоматические тесты используют эмуляторы Android и изолированные Linux/Windows
VM с синтетическими USB-устройствами. Они проверяют протокол, драйверы и ошибки,
но не доказывают совместимость всех физических моделей. Проверка Windows
Server 2022/2025 не заменяет проверку Windows 10/11, UAC и всех сочетаний
Secure Boot/Memory Integrity. SELinux проверялся на Fedora с Enforcing;
произвольные корпоративные политики и все Linux-дистрибутивы не заявлены.

Сборка
См. BUILDING.txt. Нужны Android SDK/NDK, JDK, закреплённый Rust nightly и Cargo.lock.
Публичная сборка не требует доступа к приватному репозиторию разработчика:
приёмник Windows собирают и проверяют на собственной изолированной Windows VM,
после чего локально закрепляют его артефакт. Linux-приёмник собирается из этих
же исходников. Подпись своей сборки выполняется собственным ключом.

Устройство реализации
Rust: USB-движок, протокол, ограниченные очереди, подключения, правила выбора,
приёмники и подготовка компьютера. Java: Android USB API, разрешения, жизненный
цикл и нативные экраны. В APK не встроены Python, Ansible или отдельный GUI runtime.
Контракты памяти/USB: native/usb-most/SAFETY.txt; границы платформенных API:
native/usb-most-platform/SAFETY.txt. Тесты и стенды находятся в tests/ и tools/.
