# USB Мост

**Простой доступ к USB-устройствам через сеть.**

Официальный репозиторий исходников выпусков проекта «USB Мост».
Приложение предназначено для подключения USB-устройства на Android
к удалённому компьютеру через сеть.

## Статус

Репозиторий подготовлен для публикации исходников. **Первый исходный
снимок магазинной версии ещё не опубликован.** Сейчас здесь описание,
лицензия и правила выпуска; это ещё не исходники собираемого приложения.
Ссылка на опубликованное приложение в RuStore появится после его выпуска.

Рабочая базовая версия проекта проверялась с Рутокеном Lite и Linux.
Пользователь подтвердил успешную расшифровку отчёта. Другие модели ключей,
классы USB-устройств и клиентские ОС пока не заявлены как поддерживаемые.
Универсальное название обозначает направление развития, а не совместимость
с любым USB-устройством.

## Исходники выпусков

Для каждого загружаемого в RuStore AAB/APK здесь заранее публикуются:

- полные соответствующие исходники и необходимые ресурсы;
- файлы и инструкция сборки с версиями инструментов;
- лицензии, сведения об авторах и изменениях;
- запись версии и тег `v<versionName>-vc<versionCode>`.

В основной ветке будет последний опубликованный снимок. Предыдущие
выпуски сохраняются по тегам. Промежуточная разработка ведётся отдельно.
Готовые APK и AAB в этом репозитории не размещаются.

Порядок публикации: [RELEASE-POLICY.md](RELEASE-POLICY.md).
Публичных source-тегов и инструкций сборки конкретного выпуска пока нет.

авторства Cameron Gutman. Исходники приложения распространяются по
[GNU GPLv3](LICENSE); сведения о происхождении — [NOTICE.md](NOTICE.md).

изучение, изменение, сборку и дальнейшее распространение по условиям лицензии.
Отсутствие APK в этом репозитории этих прав не ограничивает.

Проект не является официальным продуктом производителей USB-устройств,
Рутокен или КриптоПро. Названия сторонних продуктов используются для описания
совместимости. Проверка товарного знака «USB Мост» ещё не завершена.
