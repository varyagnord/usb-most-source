# USB Мост 1.0.13 · versionCode 10018

Исходники предварительного выпуска Android-приложения USB Мост и приёмников для Linux и Windows. Приложение ещё не опубликовано в RuStore.

Телефон или планшет передаёт выбранные USB-устройства компьютеру через локальную сеть, защищённое прямое TLS-подключение или SSH. Для разных сетей доступен вариант через Tailscale. Собственная инфраструктура USB Моста не требуется. macOS не поддерживается.

[Исходники этого выпуска](https://github.com/varyagnord/usb-most-source/tree/v1.0.13-vc10018) · [Инструкция сборки](BUILDING.txt) · [Лицензия GPLv3](LICENSE) · [Уведомления](NOTICE.txt).

В репозитории находятся только исходники, ресурсы и инструменты сборки. APK/AAB и ключи подписи здесь не размещаются. Состав из476 файлов и контрольные суммы перечислены в SOURCE-FILES.json. Снимки прежних выпусков сохраняются по неизменяемым тегам.

В10018 исправлен повторный запуск Linux-приёмника после соединения: новый слушатель корректно работает при TIME_WAIT, а первый переход со старой версии ожидает готовность до90секунд. Занятый работающим процессом порт по-прежнему недоступен второму слушателю.10017 удержан от подачи в магазин; его архивы и тег сохранены.

Оптимизированная сборка содержит четыре Android ABI с16КиБ выравниванием и265 сторонними лицензионными уведомлениями. Независимая сборка подготовленного состава исходников совпала с основной по содержимому APK/AAB, кроме служебных сведений Gradle о Git. Windows EXE в этой проверке использован из закреплённой MSVC-сборки с проверенным отпечатком исходников; отдельной повторной Windows-компиляцией независимая Android-сборка не является.

На эмуляторах Android8/12 прошли по1124 базовые проверки и по70 проверок обновления Linux-приёмника с активными синтетическими накопителями, отказом во время передачи, безопасным извлечением и проверкой данных. Проверены SSH/TLS, повторное сопряжение и пять кнопок синтетической мыши на Linux и Windows; AAB17→18 сохранил UID и зашифрованный профиль с выбранным компьютером.

Это ограниченные проверки собственных виртуальных стендов. Windows:11 Enterprise LTSC2024,26100.9457, существующий подписанный драйвер, Secure Boot включён. HVCI, MOTW/SmartScreen, другие версии Windows, все дистрибутивы Linux/SELinux и произвольные физические устройства не подтверждены. Изохронные передачи не поддерживаются. Текущий Windows-приёмник10018 отдельно прошёл настоящий UAC под обычным пользователем с другим администратором: отказ/подтверждение, права процессов и HTML, готовность страницы, Ctrl+C и очистка временных учётных записей. Проверки графической установки Linux на17 сохраняют отдельные границы.

Точная ссылка RuStore будет добавлена после публикации карточки. Для подготовки приёмников см.BUILDING.txt и server/. Цена магазина и права получателей по GPL — разные условия: GPLv3 сохраняется.
