# USB Мост

Передавайте выбранные USB-устройства телефона или планшета на компьютер по сети.
Этот репозиторий содержит соответствующие исходники, лицензии и инструкции сборки.

Снимок **1.0.13, versionCode 10016** подготовлен для первого выпуска в RuStore.
Приложение ещё не загружено в магазин; ссылка карточки появится после публикации.
Тег исходников: `v1.0.13-vc10016`. APK и AAB здесь не размещаются.

- До четырёх USB, отдельный выбор устройств, обнаружение подключения и отключения.
- SSH с проверкой ключа компьютера и встроенной подготовкой приёмника.
- Защищённое TLS-сопряжение по QR/коду, сохранённые компьютеры и отдельное доверие.
- Локальная диагностика, быстрые действия и запрос безопасного извлечения накопителя.
- Для разных сетей можно дополнительно использовать Tailscale. Собственного
  сервера USB Моста, аккаунта приложения и аналитических SDK нет.

Android 8.0+, USB Host/OTG. Приёмники: Windows x64 и Linux x86_64 с systemd
и модулем vhci_hcd. На Windows управляемое LAN-правило действует в частных
и доменных сетях; SSH-сервер должен разрешать обратный туннель. Для извлечения
из приложения Linux дополнительно нужен UDisks2. Драйверы конкретного USB
и прикладное ПО устанавливаются отдельно. Изохронные передачи не поддерживаются.

Для этой сборки проверены Android API 26/31/34, Windows 11 LTSC 2024
26100.1742 и Ubuntu 24.04.5: установка, SSH/TLS, повторное подключение и
синтетический HID через реальный драйвер принимающей ОС. На Windows Secure Boot
включён, Memory Integrity не проверена. Эмулятор и синтетические USB не доказывают
совместимость всех физических устройств или всех версий Windows/Linux.

Сборка: [BUILDING.txt](BUILDING.txt). Нужны закреплённые SDK/NDK, JDK, Rust nightly
и Cargo.lock. Windows-приёмник можно собрать на собственной изолированной VM;
доступ к приватному репозиторию не требуется. Экспорт исходников независимо
собран вне Git-истории; код, ресурсы, JNI и оба приёмника совпали с кандидатом.

В 10016 исправлено подтверждение экспорта отчёта: успех показывается только
после записи и закрытия потока. Проверены ошибки поставщика документов,
уничтожение процесса во время выбора файла и повторное сохранение.
